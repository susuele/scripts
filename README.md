# Scripts

这里放一些我自己日常用的脚本，按个人习惯做了些调整，留着备份，也方便以后修改。

| 脚本 | 用途 | 安装 |
| --- | --- | --- |
| Linux.do Comfort Reader | 简化 linux.do 的话题列表，调整帖子排版，方便阅读和剪藏。 | [安装](https://raw.githubusercontent.com/susuele/scripts/main/userscripts/linux-do-comfort-reader/linux-do-comfort-reader.user.js) |
| Arena History Export | 把 Arena 当前对话中已加载的消息和回答版本导出为 Markdown 或 JSON。 | [安装](https://raw.githubusercontent.com/susuele/scripts/main/userscripts/arena-history-export/arena-history-export.user.js) |
| Gemini Markdown Export | 将 Gemini 对话和 Deep Research 内容复制或下载为 Markdown。 | [安装](https://raw.githubusercontent.com/susuele/scripts/main/userscripts/gemini-markdown-export/gemini-markdown-export.user.js) |
| TMDB Ratings Enhancer | 在 TMDB 页面补充评分，列表显示 TMDB 评分，详情页显示 IMDb 和豆瓣评分。 | [安装](https://raw.githubusercontent.com/susuele/scripts/main/userscripts/tmdb-ratings/tmdb-ratings.user.js) |
